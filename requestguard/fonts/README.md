# Third-party fonts

Inter and IBM Plex Mono are third-party dependencies, not original hackathon work.
Downloaded from the Google Fonts repository. The accompanying SIL Open Font
License files permit redistribution. Dashboard generation embeds these local
font files in the output HTML; opening the page makes no font downloads.

Sources:
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Inter.ttf is a variable font; IBMPlexMono-Regular.ttf is regular weight.
