Know the boundary

Request cap. Not a dollar cap.

Protection covers calls routed through the guarded wrapper. Direct calls or replacing allowance storage can bypass it. A timeout can still be billed by the provider.

Mock token usage is unknown. Request records are in memory and are not a tamper-evident audit trail. No credential entry or live execution is available here.
